Privacy policy

Last updated November 23, 2026

Inbox Triage is a single-user tool. The only account it connects to is its owner's own Gmail account.

What it accesses

Using the Gmail permission gmail.modify, it reads message headers (sender, recipients, subject, date, Gmail category and unsubscribe header) and changes labels: it archives mail by removing the Inbox label and adds labels the owner approves. It does not read or store message bodies, and it does not delete or send mail.

Where data is stored

Headers and the action history are kept in a database on the owner's private home server. Nothing is sold, shared, or sent to third parties. The only outside requests are to Google's Gmail API and, when the owner approves an unsubscribe, to that sender's own one-click unsubscribe address.

Google user data

Inbox Triage's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The data is used only to provide the inbox triage feature to its owner.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions, after which the stored data is deleted from the home server.
